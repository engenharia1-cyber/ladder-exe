# Editor Ladder Alfatronic — Windows

Programa para criar, simular e transferir a lógica Ladder dos PLCs Alfatronic (ECU-MAX/F4 e ECU-TRM).

## Download

**[Baixar EditorLadder.zip](https://github.com/engenharia1-cyber/ladder-exe/releases/latest/download/EditorLadder.zip)** (recomendado) — versão mais recente. Extraia e execute `EditorLadder.exe`; não precisa instalar.

Ou o executável direto: [Baixar EditorLadder.exe](https://github.com/engenharia1-cyber/ladder-exe/releases/latest/download/EditorLadder.exe)

Todas as versões e o que mudou em cada uma: [Releases](https://github.com/engenharia1-cyber/ladder-exe/releases)

> O arquivo tem cerca de 145 MB e por isso fica em **Releases**, não na lista de arquivos do repositório (o GitHub não aceita arquivos acima de 100 MB no código). O botão **Code → Download ZIP** traz só este README.

> **Se o download não aparecer:** o navegador pode bloquear o .exe por não ser assinado. Abra os downloads (Ctrl+J), clique no arquivo bloqueado e escolha **Manter** / **Manter mesmo assim**. O .zip costuma não ser bloqueado.

> **Aviso do Windows:** o Windows SmartScreen pode mostrar "O Windows protegeu o computador" no primeiro uso. Clique em **Mais informações** e depois em **Executar assim mesmo**.
