# Editor Ladder Alfatronic — Windows

Programa para criar, simular e transferir a lógica Ladder dos PLCs Alfatronic (ECU-MAX/F4 e ECU-TRM).

## Download

**[Baixar EditorLadder.exe](https://github.com/engenharia1-cyber/ladder-exe/releases/latest/download/EditorLadder.exe)** — versão mais recente. Não precisa instalar: é só executar.

Todas as versões e o que mudou em cada uma: [Releases](https://github.com/engenharia1-cyber/ladder-exe/releases)

> **Aviso do Windows:** como o .exe não é assinado digitalmente, o Windows SmartScreen pode mostrar "O Windows protegeu o computador" no primeiro uso. Clique em **Mais informações** e depois em **Executar assim mesmo**.

## Versão Web

Também é possível usar o editor direto no navegador: https://engenharia1-cyber.github.io/ladder/
